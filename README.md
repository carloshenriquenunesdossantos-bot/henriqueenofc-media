# henriqueenofc-media

Artes finais (imagens e vídeos) das peças do perfil @henriqueenofc, hospedadas aqui apenas para que o agendador (Metricool) consiga baixá-las por link público e permanente.

- `instagram/AAAA-MM-DD/<peça>.jpg|mp4` — uma pasta por data de publicação.
- URL pública: `https://raw.githubusercontent.com/carloshenriquenunesdossantos-bot/henriqueenofc-media/main/instagram/AAAA-MM-DD/<arquivo>`
- `instagram/tools/make_story.py` — foto → Story 1080x1920 (texto gravado).
- `instagram/tools/make_story_video.py` — vídeo → Story de vídeo 1080x1920 (recorte 9:16, texto gravado, H.264+AAC, ≤ 60 s).

Material bruto (fotos/vídeos do iPhone e dos óculos) NÃO fica aqui: vai para o repositório privado `henriqueenofc-captura`.
